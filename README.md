# 💈 Barbearia Landing Page

Uma landing page moderna desenvolvida para uma barbearia. O projeto foi construído com foco em design de interface e estilização avançada, utilizando exclusivamente **HTML5 e CSS3 puros**, sem dependência de frameworks ou JavaScript.

## ✨ Funcionalidades

* **Navegação Fluida:** Menu superior fixo (`sticky`) com rolagem suave (`smooth scroll`) para âncoras na mesma página.
* **Efeito Glassmorphism:** Seções principais utilizam fundos semitransparentes com desfoque (`backdrop-filter`), garantindo a leitura do texto sem ocultar a imagem de background.
* **Estrutura Flexbox:** Layout organizado com CSS Flexbox para alinhar textos, imagens e criar cartões de serviços perfeitamente distribuídos.
* **Validação Nativa:** Formulário de agendamento que utiliza atributos estruturais (`required`) para forçar o preenchimento antes da submissão, utilizando o sistema de avisos do próprio navegador.
* **Gestão de Estados:** Botões de redes sociais com estilização customizada para demonstrar inatividade (`disabled`, `opacity` e `cursor: not-allowed`).

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Marcação semântica (`<header>`, `<section>`, `<nav>`, `<form>`).
* **CSS3:** Variáveis customizadas (`:root`), posicionamento (`absolute/sticky`), Flexbox, estilização de tipografia e efeitos visuais (`box-shadow`, `blur`).
